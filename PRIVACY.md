# Política de Privacidad - DolarBlue

**Última actualización:** 18 de mayo de 2026

## Información que recopilamos

DolarBlue **no recopila, almacena ni comparte información personal** de los usuarios.

La única información que se almacena es de forma **local y exclusiva en el dispositivo** del usuario:
- Historial de conversiones de la calculadora (guardado localmente con `shared_preferences`).
- Última cotización consultada (cacheo temporal para permitir uso offline).

## Permisos

La aplicación puede solicitar permisos relacionados con:
- **Acceso a Internet:** para consultar las cotizaciones actualizadas desde la API pública de Bluelytics.
- **Compartir contenido:** para enviar cotizaciones a través de otras aplicaciones (WhatsApp, redes sociales, etc.).

## Terceros

Los datos de cotización provienen de [Bluelytics.com.ar](https://bluelytics.com.ar), una API pública de acceso libre. No se comparte información del usuario con terceros.
